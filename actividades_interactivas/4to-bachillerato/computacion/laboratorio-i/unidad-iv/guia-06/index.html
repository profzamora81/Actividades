2. Lectura: repetir instrucciones en Python

En los programas que hemos trabajado, una instrucción normalmente se ejecuta una vez. Pero a veces necesitamos repetirla: mostrar varias veces un mensaje, recorrer una lista de datos o sumar cantidades. Para eso utilizamos los ciclos.

El ciclo for: repetir una cantidad conocida de veces

Usamos for cuando queremos recorrer elementos o números. La función range() permite crear una secuencia de números. Recuerde: el límite final no se incluye.

for numero in range(1, 6):
    print("Número:", numero)

Este programa muestra los números 1, 2, 3, 4 y 5. El bloque que se repite lleva cuatro espacios de sangría al inicio de la línea.

El ciclo while: repetir mientras se cumpla una condición

El ciclo while comprueba una condición antes de cada repetición. Cuando la condición deja de cumplirse, termina. La variable que controla el ciclo debe cambiar para evitar que el programa se repita indefinidamente.

contador = 1
while contador <= 5:
    print("Número:", contador)
    contador += 1

Contadores y acumuladores

Un contador registra cuántas veces sucede algo. Un acumulador guarda una suma que aumenta con cada repetición.

total = 0
for numero in range(1, 6):
    total += numero
print("Suma:", total)  # Resultado: 15
