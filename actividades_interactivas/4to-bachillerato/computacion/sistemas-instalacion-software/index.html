Instalación de Servidores Remotos en Q4OS Linux (Laboratorio Escolar)

Q4OS es una distribución Linux ligera basada en Debian. Abra la terminal (Konsole o LXTerminal) y ejecute los comandos siguientes:

# 1. Actualizar repositorios e instalar SSH Server:
sudo apt update && sudo apt install openssh-server -y
# 2. Iniciar y verificar el estado del servicio SSH:
sudo systemctl enable --now ssh
sudo systemctl status ssh
# 3. Instalar Servidor VNC (TigerVNC / TightVNC):
sudo apt install tigervnc-standalone-server tigervnc-common -y
# 4. Establecer contraseña VNC y arrancar pantalla :1 (Puerto 5901):
vncserver :1 -geometry 1280x720 -depth 24

Comandos de Diagnóstico y Conectividad

ip a / ifconfig

Identifica la dirección IP de la interfaz de red (ej. 192.168.1.15).

ssh usuario@IP_SERVIDOR

Abre la consola remota cifrada por el puerto 22.

uptime / free -m / df -h

Diagnóstico remoto: tiempo encendido, RAM libre y espacio en disco.

vncserver -kill :1

Detiene la sesión VNC activa en la pantalla especificada.

¿No terminaste en el laboratorio y usas Windows en casa?

Puedes realizar y documentar tus actividades sin inconvenientes utilizando las herramientas cliente para Windows descritas a continuación:

Actividad 1 (SSH en Windows)

Usa PuTTY o PowerShell en Windows (ssh usuario@ip). También puedes usar WSL (Windows Subsystem for Linux) o VirtualBox con Q4OS.

Actividad 2 (VNC en Windows)

Descarga RealVNC Viewer o TightVNC Viewer para Windows y conéctate a una IP remota o máquina virtual Linux local.

Actividad 3 (RustDesk/AnyDesk)

RustDesk y AnyDesk son totalmente multiplataforma. Instala la versión de Windows y conéctate a un teléfono celular o segundo equipo Windows/Linux.
