3. Caso práctico de mejoramiento

Situación: un compañero creó una máquina virtual, pero no completó correctamente la instalación. Tu trabajo consiste en preparar una instalación propia, identificar un posible error de configuración, resolverlo y demostrar que el sistema funciona. Utiliza una ISO legal y no modifiques ni formatees el sistema operativo principal del equipo.
2 puntos

Actividad 1. Diagnóstico y plan de instalación

Analiza este escenario: una máquina virtual dispone de 1 GB de RAM, un disco virtual de 8 GB y no tiene una imagen ISO montada. Se quiere instalar una distribución Linux de escritorio cuyos requisitos son superiores a esos recursos.

2 puntos

Actividad 2. Preparar y comprobar la máquina virtual

Crea una máquina virtual nueva. Registra sus ajustes antes de iniciar la instalación.

4 puntos

Actividad 3. Instalar y solucionar una dificultad

Instala el sistema operativo y registra las etapas del procedimiento. Documenta un inconveniente real o una verificación preventiva si no se produjo ningún error.
