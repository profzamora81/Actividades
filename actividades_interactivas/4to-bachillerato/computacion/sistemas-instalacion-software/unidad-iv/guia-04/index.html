2. Recurso consultado

Antes de iniciar, revisa la introducción del manual de Oracle VM VirtualBox. Concéntrate en la creación de una máquina virtual, la asignación de memoria, el disco virtual y el uso de una imagen ISO como medio de instalación.

Abrir recurso técnico: Oracle VM VirtualBox User Manual — First Steps

Utiliza únicamente una imagen ISO obtenida legalmente. Puede ser una distribución libre de Linux o un sistema operativo autorizado por el establecimiento. No se solicita evadir licencias ni activaciones.

3. Actividades

Trabaja en una máquina virtual. No formatees ni modifiques el sistema operativo principal de la computadora. Las capturas deben mostrar tu propio proceso.

Actividad 1 — Plan de instalación

Antes de instalar, registra cómo prepararás la máquina virtual.

2 pts

Actividad 2 — Preparación de la máquina virtual

Crea la máquina virtual y revisa su configuración antes de iniciar la instalación.

4 pts

Actividad 3 — Instalación documentada

Realiza la instalación y documenta tres momentos. Las capturas deben permitir seguir el proceso.

Momento A — Inicio del instalador

Debe observarse la pantalla inicial o selección de instalación.

Momento B — Configuración durante la instalación

Ejemplo: idioma, disco virtual, usuario o ajustes equivalentes.

Momento C — Sistema ya instalado

Debe observarse el escritorio, terminal o pantalla principal funcionando.
