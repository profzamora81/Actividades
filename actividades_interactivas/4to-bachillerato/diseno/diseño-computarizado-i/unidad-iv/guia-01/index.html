Contenido relacionado

Contenido 2.1.1: codificación de colores y tonos. En esta guía se trabaja la relación práctica entre RGB, CMYK y HEX para construir una paleta digital.

Propósito: Construirás una paleta de color y aprenderás a distinguir qué sistema de codificación conviene según el destino del diseño. Trabajarás con RGB para pantalla, CMYK para impresión y HEX para uso digital/web.
Entrega: trabaja durante la semana y entrega el viernes. Cuando la guía solicite un archivo o evidencia, adjúntalo directamente en Google Classroom. No utilices enlaces de Drive como sustituto del archivo solicitado. El botón Revisar mi entrega solo comprueba que existan los componentes requeridos; no asigna una nota oficial.

Actividad 1 — Comprender los sistemas de color — 3 puntos

Qué aprenderás: Distinguir RGB, CMYK y HEX según el medio de salida.

Qué debes hacer: Explica con tus palabras para qué se utiliza cada sistema y escribe un ejemplo de una pieza gráfica donde sería adecuado.
PENDIENTE — aún faltan componentes requeridos.

Actividad 2 — Construir una paleta de cinco colores — 3 puntos

Qué aprenderás: Registrar colores de manera ordenada y mantener equivalencias para diferentes medios.

Qué debes hacer: Selecciona cinco colores que funcionen juntos para una propuesta gráfica. Para cada color registra nombre, código HEX, valor RGB y valor CMYK. Puedes apoyarte en Inkscape, Photopea u otra herramienta disponible.
PENDIENTE — aún faltan componentes requeridos.

Actividad 3 — Aplicar y justificar la paleta — 4 puntos

Qué aprenderás: Seleccionar colores con intención y relacionarlos con el objetivo de una pieza gráfica.

Qué debes hacer: Aplica la paleta a una composición sencilla: portada, tarjeta, publicación para redes o pieza similar. Luego explica la función de los colores principales y verifica que el contraste permita leer el contenido.

Adjunta una captura legible de la pieza o de la paleta aplicada.

PENDIENTE — aún faltan componentes requeridos.
