Actividad 1 — Elegir el sistema de color — 2 puntos

Qué aprenderás: decidir qué sistema de color corresponde al destino de una pieza gráfica.

Qué debes hacer: analiza las dos situaciones. Selecciona el sistema que utilizarías y explica la decisión con tus propias palabras. Después indica para qué utilizarías un código HEX dentro de un trabajo digital.

Situación A — Publicación para redes sociales

Debes crear una publicación cuadrada que será vista únicamente en teléfonos y computadoras.

Situación B — Afiche para imprenta

Debes preparar un afiche que será enviado a una imprenta comercial.

Criterio de evaluación — 2 puntos

Excelente — 2 pts: identifica correctamente el sistema adecuado para pantalla e impresión y explica de forma clara el uso de HEX.

Aceptable — 1 pt: reconoce la idea general, pero una selección o explicación requiere corrección.

No cumple — 0 pts: las respuestas están ausentes o confunden de forma general los sistemas de color.

PENDIENTE — aún faltan componentes requeridos.

Actividad 3 — Diseñar para pantalla e impresión — 5 puntos

Qué aprenderás: aplicar la misma propuesta visual considerando dos destinos diferentes.

Situación de diseño: crea una pieza promocional para una actividad ficticia llamada “Muestra de Diseño Estudiantil”. Debe incluir el nombre de la actividad, una fecha ficticia, una frase breve o información complementaria y la paleta de la Actividad 2. Prepara una versión para pantalla y otra pensando en impresión. Puedes trabajar con Photopea, Inkscape, Canva u otra herramienta disponible. Si tu herramienta no cambia realmente el modo del documento a CMYK, registra los valores CMYK y explica la preparación que harías para la salida impresa.

Versión digital

Adjunta una captura legible de la pieza para pantalla.

Versión destinada a impresión

Adjunta una captura de la segunda versión o de la preparación realizada para impresión.

Criterio de evaluación — 5 puntos

Excelente — 5 pts: aplica coherentemente la nueva paleta, presenta las dos evidencias, identifica correctamente RGB/HEX para pantalla y CMYK para impresión, y explica de forma comprensible una posible diferencia entre ambas salidas.

Aceptable — 3 pts: presenta las dos versiones y la idea general es correcta, pero hay una imprecisión de color, evidencia, legibilidad o explicación que requiere corrección.

No cumple — 0 pts: faltan las evidencias principales o la entrega no permite comprobar la aplicación de la paleta y la diferencia entre pantalla e impresión.

PENDIENTE — aún faltan componentes requeridos.
