Actividad 1 — Preparación y generación del producto desplegable 3 puntos

Qué aprenderás

Preparar el sistema de información que ya desarrollaste para su distribución y obtener el producto ejecutable o distribuible correspondiente a tu proyecto.

Qué debes hacer

Trabaja con el sistema que corresponda a tu diagnóstico: proyecto propio, recuperación parcial o proyecto general de contingencia. Prepara ese sistema para distribución y genera el producto ejecutable o distribuible correspondiente a la plataforma seleccionada. Identifica y atiende los problemas que puedan impedir obtener adecuadamente el producto.

Evidencia requerida

Producto ejecutable o distribuible generado a partir del sistema utilizado según tu ruta de diagnóstico y evidencia verificable del proceso real realizado.

Actividad 2 — Creación del mecanismo de instalación 3 puntos

Qué aprenderás

Preparar un mecanismo que permita instalar el mismo sistema de información en la plataforma correspondiente al proyecto.

Selecciona primero la plataforma de tu proyecto en la sección Guía.

En Linux Q4OS uno de los dos mecanismos es suficiente.

Evidencia requerida

Mecanismo de instalación funcional correspondiente a la plataforma del proyecto: MSI para Windows; o script Bash O paquete .deb para Linux Q4OS.

Actividad 3 — Prueba del sistema instalado en un entorno limpio 2 puntos

Qué aprenderás

Comprobar el comportamiento del sistema después de instalarlo fuera de las condiciones utilizadas durante su desarrollo.

La prueba debe permitir comprobar cualitativamente

  • que el mecanismo de instalación funciona;
  • que el sistema puede instalarse;
  • que el sistema instalado puede iniciarse;
  • que los problemas de despliegue, cuando existan, pueden identificarse.

Evidencia requerida

Evidencia verificable de la instalación y ejecución real del sistema desplegado, acompañada del registro técnico de problemas encontrados cuando existan.

Actividad 4 — Documentación técnica del despliegue 2 puntos

Qué aprenderás

Documentar técnicamente el proceso real de preparación, instalación y comprobación del sistema desplegado.

Orientación para tu documentación: identifica primero la ruta utilizada (A, B o C) y el sistema con el que realizaste el despliegue. Después documenta la plataforma utilizada, producto generado, procedimiento de instalación, forma de iniciar el sistema, problemas encontrados cuando existan, solución aplicada cuando corresponda y resultado general de la prueba en limpio.

Evidencia requerida

Documentación técnica del proceso real de despliegue realizado.
